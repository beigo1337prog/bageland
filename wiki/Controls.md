| Action | Input |
|---|---|
| Pan | WASD / arrow keys, or drag with the middle mouse button |
| Zoom | Mouse wheel (zooms toward the cursor) |
| Build | Click a card in the bottom menu, then left-click on the map |
| Paint item and fluid pipes | Hold left mouse button and drag. A drag lays straight runs with one turn (not a staircase), and a line gets a Left or Right Turn piece at the corner; starting in front of an output port leaves it straight, and the last piece in front of an input port turns to feed straight in. Only pieces from the current drag change, so crossing a line never re-aims it; starting on a line's open end extends it |
| Rotate | R (Shift+R rotates the other way), for both placement and the selected building |
| Cancel | Right-click or Esc |
| Select / inspect | Left-click a building |
| Select many | Hold the left mouse button and drag a box over them |
| Move | M, or the inspector's **Move** button (a box selection moves together) |
| Pick up | Del / X / Backspace (picks up the whole box selection). Picked-up buildings go to your building inventory; buildings can't be sold |
| Change a machine's recipe | Tab cycles Auto → each recipe, Shift+Tab goes back (or click one in the inspector) |
| Copy a building's type | Q while hovering over it (it also copies the pinned recipe and setting) |
| Copy and paste | Box-select, then F6 (or **Copy**): each click builds the copy again with its facing, pinned recipes, settings, closed pipe sides and the wires inside the box. F7 picks up the last copy again; RMB / Esc lets go |
| Build a row | Hold a building bigger than one cell and drag: a row is built on release. - and = change the gap between them |
| Select every building of a type | F4 over a building (or with it selected), or **All of type** in the panel |
| Set many machines at once | Box-select machines of one type: the recipe buttons and Tab set all of them. Split valves likewise |
| Camera bookmarks | Shift+4 to Shift+9 set one, 4 to 9 fly back (saved with the world) |
| Find a stalled machine | F9, or **Stalled** in **Info views [I]**: steps through machines short of input, blocked or without power |
| Search the build menu | / (or click the box left of the tabs); Esc clears it |
| Recipe book (search, filter by tier, sort) | B, or **Recipes** in the top bar. Click an item or machine in it to search for it. Esc closes it |
| Wire power nodes / power view | C, or **Wires** in the top bar. Click node, click node; RMB / Esc lets go |
| Wiki (guide, every building, item and research topic) | H, or **Wiki** in the top bar. / searches, Up/Down step through pages, click an item or machine to open its page, Backspace goes back, Esc closes |
| Empty a pipe (throw away what is inside it) | Select the pipe, then E or **Empty**. Shift+E (**Empty run**) empties every pipe joined to it; with a box selected, E empties every pipe in the box |
| Pipe view (look inside pipes for jams) | V, or **Pipe view** in **Info views [I]** under the menu button. Items moving through item pipes show as dots of their colour. Item pipes: green flowing, red blocked, grey empty, one pip per slot, running along the pipe and filling from its front; fluid pipes show their fill; a red ring marks where a jam starts and orange what it feeds |
| Pollution view (who pollutes, who scrubs) | Z, or **Pollution** in **Info views [I]** (after Steelmaking) |
| Ground lens (what deposit is in a cell) | G, or **Ground lens** in **Info views [I]**. One info view shows at a time. Names the deposit under the cursor; deposits you haven't researched a miner for stay hidden |
| Buy land | P, or **Land** in the top bar. Click a plot for sale; RMB / Esc leaves |
| Turn a hand crank | Hold LMB or F on it and circle the mouse |
| Pause / speed | Space, 1, 2, 3, or the buttons in the top bar |
| Build menu tabs | , and . open the previous and next tab |
| Pick a card with the keys | With nothing held, [ and ] move a highlight over the open tab's cards and Enter takes it |
