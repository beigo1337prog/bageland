Each world has its own save file. A world saves when it is created, on the autosave interval from Settings (every minute by default), from the game menu or F5, when you go back to the title, when you quit (or stop Play mode), and when the window loses focus. Each autosave blinks a small disk icon in the top-right corner. The save holds your buildings and where they face, money, building inventory, pinned recipes, power wires, items inside pipes, machines and storage, game time, speed and the camera view.

The files are in `saves/` in Unity's per-user data folder, one `world_<date>_<time>.json` per world; renaming a world changes only the name inside it. A save from before worlds existed shows up in the list as "My Factory". **Gridworks → Saves → Show Save Folder** opens the folder and **Gridworks → Saves → Delete All Worlds** clears it. Saves from when the product was called FactoryGame are copied over on the first run. Turn off **Use Saves** on `GameBootstrap` to skip the title and start an unsaved world from **Default World** every time.

In the browser build the same `saves/` folder lives in the browser's IndexedDB, and every write is flushed to it straight away.
